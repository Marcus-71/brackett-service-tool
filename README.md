# Brackett Service Tool

Proprietary field-service application for **Brackett Comfort** (Brackett
Heating, Air & Plumbing) technicians. Offline-first PWA: manufacturer error
codes, diagnostic flows, service manuals, refrigerant charging calculator,
and equipment tag scanning.
